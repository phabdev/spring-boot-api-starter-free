## Title

**Spring Boot API Starter Kit Premium**

## Subtitle

A production-ready Spring Boot 3 REST API base with JWT auth, roles, PostgreSQL, Flyway and Docker. Start your next API on Monday morning, not Wednesday afternoon.

## The problem

Every new Spring Boot API starts the same way: create the project, add validation, write an exception handler, wire in security, argue with JWT filters, set up PostgreSQL, add migrations, write a Dockerfile, configure profiles. Two or three days later you have written zero business logic.

You have done this before. You will do it again. It is never quite the same, and the security part is never quite right the first time.

## The solution

A small, readable Spring Boot project that already has all of that done, tested and documented. Not a framework. Not a generator. A project you clone, rename and start adding features to.

The structure is the same one used in the free edition, so you already know your way around it.

## What's included

- Java 21, Spring Boot 3, Maven
- JWT authentication with refresh token rotation
- `register`, `login`, `logout`, `refresh` endpoints
- Role-based access control (`USER`, `ADMIN`)
- Standardized error responses, including `401` and `403`
- PostgreSQL with Flyway migrations
- `dev`, `test`, `prod` profiles
- Dockerfile and `docker-compose.yml` (API + PostgreSQL)
- Integration tests with Testcontainers
- Structured request logging
- Swagger UI with JWT authorization
- Postman collection
- Premium README, adaptation guide, deploy checklist, CHANGELOG
- Updates for the current major version

## What's not included

- No frontend (an Angular admin is a separate future product)
- No multi-tenancy
- No microservices or multi-module architecture
- No payment, email or file upload integrations
- No hosting, no deployment done for you
- No consulting or custom development

## Who it is for

- Java developers who want a clean, secured API base without reinventing it
- Freelancers who start new client projects regularly
- Small teams that want a shared, readable starting point
- Junior and mid developers who want to see how auth, migrations and Docker fit together in a real project

## Who it is not for

- Teams that already have an internal starter they are happy with
- Projects that need Kotlin, Gradle, WebFlux or a microservices architecture
- Anyone looking for a no-code or low-code tool
- Anyone expecting a full SaaS with billing and admin UI included

## FAQ

**Is this the same as the free repository?**
No. The free repository is the CRUD skeleton: DTOs, validation, error handling, Swagger, H2, tests. The premium kit adds security, PostgreSQL, migrations, Docker, profiles and documentation for real deployments.

**Can I use it in client projects?**
Yes. You can use it in as many personal and commercial projects as you want. You cannot resell or publish the kit itself.

**Which versions does it target?**
Java 21 and the current Spring Boot 3 line at the time of release. Dependency updates within the same major are included.

**Does it come with support?**
Email support for setup problems and bugs in the kit. It does not include help with your own code or architecture consulting.

**Do I get updates?**
Yes, for the current major version of the kit.

**How is it delivered?**
Access to a private GitHub repository or a zip download, depending on the platform.

**Can I get a refund?**
Since this is source code, refunds are handled case by case. If the kit does not build as documented and I cannot fix it with you, you get your money back.
